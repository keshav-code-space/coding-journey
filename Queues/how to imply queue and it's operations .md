# Queue Data Structure

## What is Queue ? 

A Queue is linear data sturcture that follows:
```text
FIFO (First In First Out)
```

The first element inserted is the first element removed.

Example:

```text
Front                    Rear
 ↓                         ↓
10  →  20  →  30  →  40
```

Removing an element:

```text
Dequeue()

Front               Rear
 ↓                    ↓
20  →  30  →  40
```

---

## Real-Life Examples

### Ticket Counter

```text
Person A arrives
Person B arrives
Person C arrives
```

Service Order:

```text
A → B → C
```

---

### Printer Queue

```text
Print Job 1
Print Job 2
Print Job 3
```

Printing Order:

```text
Job 1 → Job 2 → Job 3
```
